# 提示词日志 — 408 考研复习助手开发全流程

## 项目背景
用户为编程初学者，在 MacBook 上开发 408 考研复习助手，目标是科学管理知识点复习进度。

---

## 阶段 0：需求调研与确认

### 用户初始需求表述
> 在学习中主要有的问题是无法掌握每一个知识点复习的熟练程度和所有知识点的学习进度，以及在知识点众多的情况下不知道目前最该复习的是哪个知识点。
> 需求有：要能够按章节整理考纲知识点，然后可以自主评价和科学分析结合控制知识点的熟练掌握程度，然后有各科知识点的进度和掌握程度统计。

### AI 需求澄清提问
四个关键问题：
1. 知识点内容深度：标题+状态为主，还是需要详细内容？
2. 数据存储方式：浏览器 localStorage 还是本机 JSON 文件？
3. 技术方案倾向：纯网页版还是 Python + Streamlit？
4. 知识点初始内容：AI 预置还是用户手动添加？

### 用户最终决策
1. 先标题+状态，后续支持手动添加详细内容
2. 本地存储（localStorage）
3. 纯网页版（HTML + CSS + JS），容易部署
4. 预置 408 完整考纲知识点

### 关键技术提示词
```
在开始开发之前，请你先规划一下开发步骤，不要一口气做太多，让项目稳定安全有效的推进。
在项目文件夹里创建一个开发日志文件夹，每天自动记录完成开发事项和待办事项。
再创建一个docs文件夹，放入项目开发相关的需求、技术、设计规范、执行步骤等等具体标准文件。
在你的CLAUDE.md文件中添加指引各标准文件路径以及工作说明。
```

## 阶段 8：GitHub 部署

### 用户指令
> 今天我打算先完成这么多，在日后再进行功能的拓展。我希望保存今天的进度然后将项目部署上线到我的GitHub上，我要怎么处理

### 遇到的问题与解决

| 问题 | 解决方案 |
|------|----------|
| GitHub HTTPS 超时 | 改用 SSH 连接 |
| HTTP/2 帧错误 | 受 VPN 干扰，改用 SSH |
| VS Code 发布分支循环确认 | 手动执行 `ssh-keyscan github.com >> ~/.ssh/known_hosts` |

### 关键操作步骤
1. 配置 Git 用户名和邮箱
2. 生成 SSH 密钥（ed25519）
3. 添加公钥到 GitHub Settings
4. 添加 known_hosts 信任
5. VS Code 源代码管理面板 → 发布分支

## 项目开发模式总结

### 有效的工作流
1. **需求先行**：先聊清楚要做什么，再动手写代码
2. **小步推进**：每阶段 2-4 个文件，立即验证
3. **文档驱动**：需求/技术/设计/计划四份规范文档指导开发
4. **每步验证**：用户亲自测试每个阶段产出，确认后再继续
5. **遇到问题即时排查**：网络问题、文件关联问题当场解决

### 关键决策点
- 技术选型：纯网页版（HTML + CSS + JS），零依赖
- 存储方案：浏览器 localStorage
- 算法选择：SM-2（SuperMemo 经典间隔重复算法）
- 部署方式：Git + GitHub Pages
