# 408 考研复习助手

一个帮助你科学管理 408 考研复习进度的本地工具，纯网页应用，双击即用。

## 快速开始

双击 `index.html`，用浏览器打开即可使用。所有数据保存在浏览器本地，不会上传到任何地方。

## 三大功能

### 1. 仪表盘（首页）

打开就看到今日最该复习的知识点列表，按紧急度排序：
- 🔴 红色 = 超期未复习，需要立即复习
- 🟠 橙色 = 该复习了
- ⬜ 灰色 = 还没学过

直接在卡片上点击自评按钮（完全不会 / 有点印象 / 基本掌握 / 完全掌握），系统会自动安排下次复习时间。

### 2. 知识点浏览

左侧树形目录按「科目 → 章 → 节 → 知识点」四级组织，点击展开折叠。选中知识点后右侧显示详情，可以在此打分和查看复习记录。

### 3. 统计面板

查看各科学习进度和整体掌握情况，包括：
- 知识点总数 / 已学数 / 整体掌握率
- 四档掌握程度分布
- 各科进度条与细分统计

## 间隔重复原理

系统使用 SM-2 算法（SuperMemo 的经典间隔重复算法），根据你的自评结果自动安排复习间隔：

| 自评 | 效果 |
|------|------|
| 完全不会 | 明天就复习 |
| 有点印象 | 重置间隔 |
| 基本掌握 | 间隔逐渐拉长 |
| 完全掌握 | 间隔快速拉长（1→3→7→14→...天） |

连续评为"完全掌握"的知识点，复习间隔会越来越长；评为"不会"的则会重置为每天复习。

## 数据备份

在浏览器控制台（`Cmd + Option + C`）中执行：

```js
Storage.exportAll()
```

即可下载 JSON 格式的备份文件。换电脑或换浏览器后可以后续通过导入功能恢复（后续版本）。

## 技术说明

- 纯 HTML + CSS + JavaScript，无框架依赖
- 数据存储在浏览器 localStorage
- 兼容 Chrome、Safari、Edge、Firefox
- 完全离线可用
