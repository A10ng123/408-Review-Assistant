# 408 考研复习助手 — 设计规范

## 设计原则

- 简洁清晰，减少视觉噪音
- 信息层级分明，核心功能（复习推荐）优先展示
- 颜色用于传达信息（掌握程度），而非装饰

## 色彩系统

```css
--color-primary: #4A90D9;        /* 主色，按钮、链接 */
--color-success: #52C41A;        /* 完全掌握 */
--color-warning: #FAAD14;        /* 基本掌握 */
--color-caution: #FA8C16;        /* 有点印象 */
--color-danger: #F5222D;         /* 完全不会 / 紧急 */
--color-bg: #F5F7FA;            /* 页面背景 */
--color-card: #FFFFFF;           /* 卡片背景 */
--color-text: #1A1A2E;           /* 主文字 */
--color-text-secondary: #8C8C8C; /* 次要文字 */
--color-border: #E8E8E8;        /* 边框 */
```

## 掌握程度配色规则

| 等级 | 颜色 | 使用场景 |
|------|------|----------|
| 完全掌握 | 绿色 `#52C41A` | 知识点标签、进度统计 |
| 基本掌握 | 黄色 `#FAAD14` | 知识点标签、进度统计 |
| 有点印象 | 橙色 `#FA8C16` | 知识点标签、进度统计 |
| 完全不会 | 红色 `#F5222D` | 知识点标签、进度统计 |

## 紧急度配色规则

| 紧急度 | 说明 | 颜色 |
|--------|------|------|
| 高 | 超过计划复习时间 3 天以上 | 红色 |
| 中 | 超过计划复习时间 1-3 天 | 橙色 |
| 低 | 未到复习时间或刚过 | 绿色/灰色 |

## 视图说明

### 视图 1：仪表盘（首页）

- 今日推荐复习列表（核心，占主要区域）
- 各科进度概览（侧边栏或底部）
- 今日复习完成情况计数

### 视图 2：知识点浏览

- 左侧：树形知识点导航（四级可展开折叠）
- 右侧：选中知识点详情 + 自评按钮 + 复习历史

### 视图 3：统计面板

- 各科知识点总数 / 已学数进度条
- 掌握程度分布饼图/条图
- 四科对比概览

## 交互规范

- 知识点树点击：展开/折叠章节目录，点击知识点加载详情
- 自评按钮：四档一键点击，点击后即时更新颜色和 SM-2 状态
- 复习完成：在推荐列表中勾选"已复习"，弹出四档自评
- 所有操作无需确认弹窗，可撤销（后续版本）
- 数据修改自动保存到 localStorage，无需手动保存
