# 408 考研复习助手 — 需求规格说明

## 项目背景

用户为跨考/计算机初学者，在 MacBook 上开发 408 专业课复习工具。408 考试包含四门课：数据结构、计算机组成原理、操作系统、计算机网络。

核心痛点：知识点数量庞大且分散，无法精确掌握每个知识点的熟练程度和整体学习进度，不知道当前最应该复习哪个知识点。

## 功能需求

### FR-1 知识点浏览

- 四级树形结构：科目 → 章 → 节 → 知识点
- 支持展开/折叠任意层级
- 知识点默认以"标题"方式呈现
- 点击知识点可查看详情（标题、掌握状态、自评历史）
- 支持后续手动为知识点添加详细内容（定义、考点、笔记等）

### FR-2 熟练度自评

- 每个知识点支持四档自评：完全不会 / 有点印象 / 基本掌握 / 完全掌握
- 自评记录历史，可追溯每次评价时间
- 自评结果即时反馈到界面（颜色标识）

### FR-3 间隔重复系统

- 基于 SM-2 算法
- 每次自评后自动计算下次复习时间
- 自评"完全不会"→ 间隔重置为 1 天
- 连续自评"完全掌握"→ 间隔逐次拉长（1→3→7→14→30→60 天）
- 超过预定复习时间未复习 → 标记为"过期"，紧急度提升

### FR-4 今日复习推荐

- 首页（仪表盘）核心区域展示
- 按紧急度从高到低排序
- 紧急度计算因子：距上次复习天数 / 计划间隔、历史自评分数
- 每条推荐显示：知识点名称、所属科目、上次复习时间、紧急度等级
- 点击可快速跳转到知识点详情完成复习

### FR-5 进度与统计

- 各科进度条：已学知识点数 / 总知识点数
- 掌握程度分布：按"完全掌握/基本掌握/有点印象/完全不会"四档统计
- 今日复习完成数 / 推荐数
- 预留后续扩展：复习日历、连续打卡

### FR-6 数据持久化

- 所有用户数据保存在浏览器 localStorage
- 初始加载时读取预置考纲数据
- 用户自评数据、复习记录自动保存
- 提供"导出数据"和"导入数据"功能（后续版本）

## 非功能需求

- **零安装**：双击 index.html 即可在浏览器中运行
- **离线可用**：无网络依赖
- **响应式**：适配 MacBook 屏幕（主要支持 1280x800 以上分辨率）
- **数据安全**：所有数据仅存储在用户本机浏览器
