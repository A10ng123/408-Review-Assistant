# 408 考研复习助手 — 开发执行计划

## 开发原则

- 每阶段独立可验证，完成后用户确认再进行下一阶段
- 每阶段不超过 3-4 个文件修改
- 每阶段完成后更新 devlog

---

## 阶段 1：项目骨架搭建

**目标**：空项目能跑起来，验证文件结构正确

**产出**：
- `index.html`：基础 HTML 骨架，顶部导航（仪表盘/浏览/统计 三个 Tab）+ 三个视图占位
- `css/style.css`：CSS 变量定义、基础布局（Flexbox/Grid）、导航栏样式
- `js/app.js`：简单的 Tab 切换逻辑

**验证**：双击 index.html 能在浏览器中看到三个 Tab 可切换的空白页面

---

## 阶段 2：数据层 + 预置考纲

**目标**：知识点数据就位，localStorage 读写可用

**产出**：
- `js/data.js`：预置 408 四门课完整考纲知识点（科→章→节→点）
- `js/storage.js`：localStorage 读写封装（读取、保存、合并预置数据与用户数据）
- `js/app.js`：初始化时加载数据，控制台可验证

**验证**：浏览器控制台执行 `krData` 能看到完整知识点树，`localStorage` 中有持久化数据

---

## 阶段 3：知识点浏览视图

**目标**：能浏览知识点树，点击查看详情

**产出**：
- 更新 `js/app.js`：渲染树形知识点导航（递归渲染，展开/折叠）
- 更新 `css/style.css`：树形列表样式、选中高亮、掌握状态颜色
- 知识点点击 → 右侧显示详情（名称、当前掌握状态）

**验证**：左侧树形结构可展开折叠，点击知识点右侧显示详情

---

## 阶段 4：SM-2 算法 + 自评功能

**目标**：用户可对知识点打分，系统自动计算下次复习时间

**产出**：
- `js/sm2.js`：SM-2 算法核心函数（计算间隔、难度系数、下次复习日期）
- 更新 `js/app.js`：知识点详情区域加入四档自评按钮，点击后更新 SM-2 状态并保存
- 更新 `css/style.css`：自评按钮样式

**验证**：选择一个知识点，连续点击"完全掌握"→ interval 递增；点"完全不会"→ interval 重置

---

## 阶段 5：仪表盘 + 今日推荐

**目标**：首页显示按紧急度排序的复习推荐

**产出**：
- 更新 `js/app.js`：仪表盘视图，计算所有知识点的紧急度，排序展示推荐列表
- 推荐列表中直接嵌入四档自评按钮
- 更新 `css/style.css`：推荐卡片样式、紧急度颜色标识

**验证**：对部分知识点自评后，首页按紧急度排列，超期未复习的排在最前

---

## 阶段 6：统计面板

**目标**：可视化展示各科进度和掌握程度分布

**产出**：
- 更新 `js/app.js`：统计视图，计算各科数据（进度百分比、掌握分布）
- 纯 CSS 实现进度条和简单柱状图（不引入第三方库）
- 更新 `css/style.css`：进度条、统计卡片样式

**验证**：自评不同科目的知识点后，统计页数据正确更新

---

## 阶段 7：收尾完善

**目标**：整体打磨、使用说明、最终验证

**产出**：
- `README.md`：用户使用说明
- 全局样式微调、响应式适配
- 边界情况处理（无数据、全部未学等空状态）
- 最终全流程验证

**验证**：按 docs/requirements.md 逐个功能验证通过

---

## 完成标准

- [ ] 知识点浏览：四级树形结构完整，展开折叠正常
- [ ] 自评打分：四档自评即时生效，自动保存
- [ ] SM-2 算法：间隔计算正确，下次复习时间合理
- [ ] 今日推荐：紧急度排序正确，超期优先
- [ ] 统计面板：进度条、分布图数据准确
- [ ] 数据持久化：关闭重开数据不丢失
- [ ] 离线可用：无网络环境下正常使用
